KAJITORU AI & Digital Quick Assessment
30分無料診断 質問票

目的
顧客のAI / DX / Cloud & Data / Security / 推進体制の現在地を短時間で整理し、「次に何をやるべきか」を明確にする。

事前フォーム
1. 会社名
2. メールアドレス
3. 課題感（複数選択）
   - AI活用
   - DX・業務改善
   - Cloud / Data
   - Security / Governance
   - PM・推進人材不足
   - まだ明確ではない

当日30分ヒアリング
0-3分 目的確認
・今回30分で整理したいことは何ですか？
・今日の時点で、最も困っていることは何ですか？

3-10分 AI
・生成AIは全社利用、部門利用、個人利用のどの段階ですか？
・PoCまたは本番導入したAIテーマはありますか？
・AI導入で一番大きな障壁は、テーマ、データ、技術、セキュリティ、人材のどれですか？
・システム開発工程でAIを活用していますか？

10-17分 DX
・手作業、属人化、二重入力が多い業務はどこですか？
・DX案件で止まりやすいのは、企画、意思決定、要件定義、開発、定着のどこですか？
・社内にPM / PMO / 業務設計を担える人は十分ですか？
・最終的に内製化したい領域はありますか？

17-23分 Cloud & Data / Security
・主要システムはオンプレ、Azure、AWS、SaaSのどこにありますか？
・経営や現場で必要なデータを横断して見られますか？
・Power BI / Fabric / DWH等の利用状況は？
・ID、権限、ログ、データ分類、AI利用ルールで不安はありますか？

23-27分 経営優先度
・このテーマを半年放置した場合、何が困りますか？
・成果を測るなら、売上、コスト、工数、品質、スピードのどれですか？
・3か月以内に小さく結果を出すなら、どの業務が候補ですか？

27-30分 仮説提示
・優先課題3つ
・Quick Win 1-3件
・今すぐやらないこと
・次の有償テーマ候補

スコアリング
各項目1-5点
AI Readiness
DX Execution
Cloud Foundation
Data Utilization
Security & Governance
Delivery Capability

スコアの意味
1 未着手
2 個別対応
3 一部標準化
4 全社展開
5 継続改善・高度化

診断の原則
・無料で詳細設計まで行わない
・課題を全部解こうとしない
・優先順位を3つに絞る
・有償提案は課題との接続が明確な場合だけ行う
